Threat Intelligence
Zero-Day & Hybrid Detection
How our autoencoder detects threats never seen before
⚡
What is a Zero-Day?
No known signature in any database. Traditional AV fails. We detect it using an autoencoder trained only on benign samples — high reconstruction error = anomaly.
🧠
Hybrid Architecture
  • AE learns normal behaviour from benign samples
  • Latent z + Reconstruction Error = hybrid features
  • XGBoost hybrid classifier → final verdict
  • File: EMBER 2381 features · URL: lexical + BERT
z = Enc(x) · E = Σ(xᵢ−x̂ᵢ)²/n
🔄
Polymorphic Malware
Mutates binary on every replication. Our model classifies on structural behaviour (entropy, API calls, sections) — mutation-resistant.
📊
Confidence Score
  • ≥ 50% → MALICIOUS
  • 25–49% → SUSPICIOUS
  • < 25% → BENIGN
ML Pipeline
STEP 1
Feature Extraction
File: EMBER 2381 (byte histogram, entropy, PE headers, imports). URL: Lexical + BERT + character embeddings.
STEP 2
Autoencoder
Encoder → latent z. Decoder → reconstruction. MSE error = anomaly score. High error = zero-day candidate.
STEP 3
Hybrid XGBoost
Input: [latent z + recon error]. XGBoost learns when anomalies = malicious. Output: P(malicious) 0–1.
